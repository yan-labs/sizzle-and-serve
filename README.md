Sizzle & Serve: a 2-minute diner shift. Tickets land on the order board, each naming a dish — Classic Burger, Cheeseburger, Garden Salad, Loaded Fries, Double Stack. Cook patties on the grill and fries in the fryer (both burn if you forget them), stack the dish on your plate, and serve it before the ticket's patience runs out. Keyboard and mouse, no build step, no network.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Play it locally: serve `game/` with any static server and open `game/index.html` (for example `python3 -m http.server` inside `game/`).
